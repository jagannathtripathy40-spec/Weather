🌤️ Weather App

A simple and beginner-friendly Weather App built using HTML, CSS, and JavaScript.

📌 About the Project

This Weather App allows users to enter a city name and interact with a simple weather interface.

It is created as a beginner-level frontend project to practice HTML, CSS, and JavaScript.

🚀 Technologies Used

- HTML5
- CSS3
- JavaScript

✨ Features

- Simple and clean user interface
- City name input field
- Search button
- JavaScript-based interaction
- Basic responsive styling

📂 Project Structure

WeatherProject/
│
├── index.html
└── README.md

▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Run using Live Server or open it in your browser.
